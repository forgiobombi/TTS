# Frequently Asked Questions

**Is VoxRelay free?** Yes. Its application code is licensed under MIT. Some optional third-party components have their own licensing terms.

**Is an account required?** Not for the standard online Edge TTS voice workflow.

**Does it work offline?** Only after you have installed a compatible local TTS model. Cloud voices need internet access.

**Can I speak Italian, Brazilian Portuguese or another language?** Yes, if the selected voice supports it. The interface language is a separate setting.

**Can I send speech into Discord or games?** Yes, using the VB-Cable virtual microphone on Windows. Choose `CABLE Output` as the microphone in the receiving app.

**Does it work on macOS/Linux?** The current downloadable installer and auto-updater target only Windows x64.

**Can I turn off automatic updates?** Choose **Settings → Updates → Manual**, or explicitly disable packaged self-updates for testing via the supported environment variable.

**Can I upgrade without losing shortcuts/models?** The app retains the pre-existing data location during rebranding, so normal in-place upgrades preserve them.

**Why does SmartScreen warn?** The builds are not currently Authenticode-signed. Verify file origin and checksum before installation.

**Where are downloads?** [GitHub Releases](https://github.com/forgiobombi/TTS/releases/latest).
