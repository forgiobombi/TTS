# Contributing

Contributions are welcome through issues and pull requests.

1. Fork and branch from `main`.
2. Keep changes focused and describe what they fix.
3. Run the locale validator, TypeScript check and unit tests.
4. Update relevant documentation and tests.
5. Send a PR and include screenshots when editing the UI.

**Translation contributions:** English is the source catalog. Keep localization JSON keys and named placeholders such as `{count}` unchanged. See [Voices and Languages](Voices-and-Languages).

**Reporting bugs:** use [GitHub Issues](https://github.com/forgiobombi/TTS/issues) and provide safe repro instructions, environment and logs with personal data removed.

See the repository's [CONTRIBUTING.md](https://github.com/forgiobombi/TTS/blob/main/CONTRIBUTING.md) and [Code of Conduct](https://github.com/forgiobombi/TTS/blob/main/CODE_OF_CONDUCT.md).
