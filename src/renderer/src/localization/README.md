# VoxRelay translations

The canonical source is **en.json** (English). Edit **it.json** and **pt-BR.json** with any text editor, via GitHub pull requests or by importing them into Tolgee/Crowdin/Weblate as flat JSON key-value files.

- Keep keys unchanged and preserve placeholders such as `{count}` and `{error}`.
- Select interface language in **Settings > App language**; new users start in English.
- UI language and synthesized voice locale are intentionally independent.
- Unknown keys fall back to their English source (and finally the key itself).
- These initial catalogs cover the main screens, not every message in the app yet. Contributors can extend them with more IDs.

Crowdin's gratis open-source program requires a publicly available source repository and approval. This repository is currently private; do not assume a free Crowdin license was granted. Tolgee Cloud's no-cost tier is an alternative subject to its current usage limits. No external project has been created on the user's behalf.
